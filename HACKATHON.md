# Meta Global AI Developer Hackathon 2026

Graphicle is entered in the startup track of Meta's Global AI Developer Hackathon, 26 October to 4 November 2026. The event's rules ask entries built on an existing product to say clearly what is new. This page does that, and it is updated as work lands.

## Before the event

- **Graphicle 0.1.8**, released on 26 October 2026 before the kickoff, is the baseline.
- **Written on 26 October before the kickoff, and not released before the event:**
  - a first version of `graphicle pack`, which fills a token budget with the parts of a repository a question needs;
  - first versions of `graphicle ask --pack` and `graphicle plan`;
  - a Meta Model API profile for Muse Spark, and Muse Code in `graphicle setup`;
  - the harness and question sets of the whole-repository benchmark, and a first tuning round on its two development repositories (kubernetes and home-assistant).

## Built during the event

Everything below was started after the kickoff, at 26 October 2026, 16:00 UTC. Each item names the release it shipped in.

The commit ids are those of Graphicle's development repository, with the times they were committed (UTC); this public repository receives each release as one commit. From 0.1.10 on, items give times without ids. The commands that call Meta's models were tested against stand-ins for the Meta Model API (the tests' local servers and [`demo/mock_meta.py`](demo/mock_meta.py)), not against the live API; the [0.1.9 notes](CHANGELOG.md#019---2026-10-28) say so feature by feature.

- **Cache-aware packs, the spend log and `graphicle fix`** (0.1.9). `graphicle pack --layout cache` puts first a repository part that is the same bytes for every question about a commit, so Meta's prompt cache can serve it. With `--layout cache`, `ask --pack`, `plan` and `fix` send a prompt cache key to the Meta Model API; they ask it for exact token counts near the input limit, log each call's tokens and cost (`graphicle usage`), and refuse a call past a profile's cost caps. `graphicle fix` makes a change for an issue on a new branch in a new worktree and runs your tests on it. Commits `3e0d7e8` (26 October, 17:08), `854c0cc` to `925f8c8` (5 commits, 26 October, 17:42 to 18:29), and two rounds of review fixes: `1e566f8` to `7ad616b` (2 commits, 26 October, 19:17) and `ad89536` to `4233438` (2 commits, 27 October, 01:20). `graphicle fix` packs in the standard layout by default, so the whole budget goes to the files the issue needs: `4578a5a` (27 October, 09:13).
- **The whole-repository benchmark** (its kit and page, 0.1.9). The grid of model runs, fixed before any model call; the runner, with the prompt cache and spending limits; the cost of a question with the prompt cache, computed at list prices and not billed; and the held-out baseline of the pack written before the event. Commits `c5ca2ca` to `0883169` (11 commits, 26 October, 16:58 to 27 October, 01:00). Three development repositories for TypeScript, Java and C++ (angular, keycloak and godot): `a1f83cf` (27 October, 02:39). The benchmark's model runs have not been made yet.
- **Pack ranking for TypeScript, Java and C++** (0.1.9). A second tuning round on the five development repositories, then one measurement on the three held-out repositories, whose numbers are in the 0.1.9 notes: `cbbf016` (27 October, 05:08). An issue whose title names a version is ranked as written instead of being refused as an empty question: `acf5f4e` (27 October, 07:20). Then the review's fix to how a pack reads an issue's environment sections: only a label below the title opens one, an issue form's question counts, and a `<name> version: <value>` line is left out; the results of all 200 development questions are unchanged, and the held-out questions were not measured again: `b8023f1` to `2955bba` (8 commits, 27 October, 08:56 to 11:34).
- **Pixel to code and the hosted demo** (0.1.9). `graphicle pixel` finds the code that draws an element of a screenshot: SAM 3.1 finds the element, a vision model (Muse Spark by default) reads it, and Graphicle looks up its strings in the code. [`demo/`](demo/README.md) is a small web app for trying Graphicle with Meta's models; it is not deployed. Commits `2dff779` to `8c352e8` (3 commits, 27 October, 01:51 to 02:18) and `2ec27e2` (27 October, 02:41).
- **`graphicle review` and its GitHub Action** (0.1.9). A review of a change from a cache-aware pack, each comment checked against the changed lines and its citations before it is shown, and a composite GitHub Action that posts one review on a pull request. Commits `92e89fc` to `04dbf74` (3 commits, 27 October, 02:21 to 02:26).
- **Graphicle inside Muse Code** (0.1.9). A native Muse Code plugin (the MCP server, a skill and hooks), session memory through Muse Code's session logs, a two-session memory demo, a harness that measures Muse Code with and without the plugin, and docs for Claude Code and Codex on Meta's models. Commits `586c339` to `99a1a1d` (6 commits, 27 October, 06:22 to 07:00). The review's fixes, `647941a` to `e580002` (6 commits, 27 October, 08:56 to 09:18): the plugin is a preview that you add with `graphicle connect muse --hooks`, since it has not yet run in Muse Code itself; its server is marked optional; the docs say to run `graphicle disconnect muse` before uninstalling; and the probe also records what Muse Code does when a plugin's server cannot start.
- **See it, find it, fix it, check it** (0.1.9). `graphicle see` drives a web app with computer use on the Meta Model API until a bug shows; `graphicle fix --focus` puts the places `graphicle pixel` finds first in the pack; `graphicle pixel` follows the keys of English JSON locale files; and [`demo/flow/flow.py`](demo/flow/flow.py) runs the whole path, from the bug on the screen to a tested fix, with a receipt. Commits `d3f3ec3` to `fd37c39` (6 commits, 27 October, 06:26 to 06:57), and the review's fixes, `dc48880` to `7e50e4f` (9 commits, 27 October, 07:55 to 08:59): the Meta key kept from the browser driver, the tests and the app's build, a browser that blocks service workers and closes WebSockets to other origins, one budget for a whole run, the model's reasoning replayed from step to step, screenshots counted by their size, and the docs saying the flow has run only against the stand-in.
- **Setup where it cannot write a file** (0.1.9). As in Claude Code's sandbox, which does not let it write `.git/hooks` or `.mcp.json`: a file setup cannot write is skipped with its reason, and the summary gives the lines to add by hand. Reported by Thomas Thomsen in [#15](https://github.com/Graphicle-AI/graphicle/issues/15). Commit `f29a86b` (27 October, 08:55). Then the rest of the issue: a hooks file setup cannot write (Claude Code's `.claude/settings.local.json`, Codex's `~/.codex/hooks.json`) is skipped with its reason while the agent stays connected, and a read-only `.git` keeps its exclude file while the summary gives the lines to add: `e1c0788` to `66643b6` (4 commits, 27 October, 11:52 to 11:59).

- **Whole top files in standard packs** (0.1.10). A standard pack of 32,768 tokens or less holds its first ranked file whole when the file fits in half the budget, and one of 131,072 tokens or more its first two when each fits in a quarter; the settings were tuned on the development repositories, then measured once on the held-out ones and on SWE-bench Pro (where a diagnosis of 0.1.9 chose the change's directions, though not its settings), and the [0.1.10 notes](CHANGELOG.md#0110---2026-10-30) give the numbers. Written 27 October, 19:36 to 20:52 UTC.
- **A folder's HTML files kept as they are** (0.1.10). Packs, search and edits read a page's own lines instead of the text extracted from it. The code review's fixes: a page past the text-file limit or not in UTF-8 is converted as before, the pages an earlier version converted are synced again, `graphicle review` escapes markup in what it posts to GitHub, an XML pack keeps a page's closing tags inside CDATA, pinned passages keep their room, and HTML files no longer count as notes. Written 27 October, 17:44 to 19:36; the review's fixes 28 October, 03:40.
- **SWE-bench Pro and line-level recall** (0.1.10). A kit that measures without a model how often a context holds every file and every line a fix changes, on 633 tasks of SWE-bench Pro's public set, with the scripts of its model runs, whose results are not in this release, and new arms and scoring for the whole-repository runner. The same count at line level for the whole-repository questions. The public tables, the kits' settings and the entries of the 0.1.10 notes. Written 27 October, 06:04 to 21:02, and 28 October, 07:48 to 08:04.

A model profile with an API key may use plain HTTP to a server on your own network whose exact host is listed in `GRAPHICLE_PROVIDER_HTTP_KEY_HOSTS`, which is off by default and sends the key in clear text, as asked in discussion #16. Written 30 October, 06:07 to 06:19 UTC.
