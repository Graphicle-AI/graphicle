# Meta Global AI Developer Hackathon 2026

Graphicle is entered in the startup track of Meta's Global AI Developer Hackathon, 26 October to 4 November 2026. The event's rules ask entries built on an existing product to say clearly what is new. This page does that, and it is updated as work lands.

## Before the event

- **Graphicle 0.1.8**, released on 26 October 2026 before the kickoff, is the baseline.
- **Written on 26 October before the kickoff, and not released before the event:**
  - a first draft of `graphicle pack`, which fills a token budget with the parts of a repository a question needs;
  - first drafts of `graphicle ask --pack` and `graphicle plan`;
  - a Meta Model API profile for Muse Spark, and Muse Code in `graphicle setup`;
  - the harness and question sets of the whole-repository benchmark, and a first tuning round on its two development repositories (kubernetes and home-assistant).
- Every change to these drafts after the kickoff is event work, and is listed below.

## Built during the event

Everything below was started after the kickoff, at 26 October 2026, 16:00 UTC. Each item names the release it shipped in.

The commit ids are those of Graphicle's development repository, with the times they were committed (UTC); this public repository received that repository's work for each release up to 0.1.11 as one commit, and 0.1.12's work as separate commits. From 0.1.10 on, items give times without ids. The commands that call Meta's models were tested against stand-ins for the Meta Model API (the tests' local servers and [`demo/mock_meta.py`](demo/mock_meta.py)), not against the live API; the [0.1.9 notes](CHANGELOG.md#019---2026-10-28) say so feature by feature. From 30 October 2026, the flow and the benchmarks' runs on Muse Spark and Muse Wonder also ran against the live Meta Model API, and the open-weights runs against Muse Spark Open on Fireworks' serverless API ([docs/flow.md](docs/flow.md) gives the flow's runs).

- **Cache-aware packs, the spend log and `graphicle fix`** (0.1.9). `graphicle pack --layout cache` puts first a repository part that is the same bytes for every question about a commit, so Meta's prompt cache can serve it. With `--layout cache`, `ask --pack`, `plan` and `fix` send a prompt cache key to the Meta Model API; they ask it for exact token counts near the input limit, log each call's tokens and cost (`graphicle usage`), and refuse a call past a profile's cost caps. `graphicle fix` makes a change for an issue on a new branch in a new worktree and runs your tests on it. Commits `3e0d7e8` (26 October, 17:08), `854c0cc` to `925f8c8` (5 commits, 26 October, 17:42 to 18:29), and two rounds of review fixes: `1e566f8` to `7ad616b` (2 commits, 26 October, 19:17) and `ad89536` to `4233438` (2 commits, 27 October, 01:20). `graphicle fix` packs in the standard layout by default, so the whole budget goes to the files the issue needs: `4578a5a` (27 October, 09:13).
- **The whole-repository benchmark** (its kit and page, 0.1.9). The grid of model runs, fixed before any model call; the runner, with the prompt cache and spending limits; the cost of a question with the prompt cache, computed at list prices and not billed; and the held-out baseline of the pack written before the event. Commits `c5ca2ca` to `0883169` (11 commits, 26 October, 16:58 to 27 October, 01:00). Three development repositories for TypeScript, Java and C++ (angular, keycloak and godot): `a1f83cf` (27 October, 02:39). The benchmark's model runs were made later, on 30 October.

[`demo/`](demo/README.md) is a small web app for trying Graphicle with Meta's models; it is not deployed.
