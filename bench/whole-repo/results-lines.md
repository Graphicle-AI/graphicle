# Line-level recall without a model: Graphicle 0.1.9 and the 0.1.10 candidate build

**What was counted.** For each question of the whole-repository benchmark and each budget, `lines.py run` builds a context from the repository at the question's snapshot S and records which of the fix's changed lines it holds. No model is involved. A question's gold lines come from its pull request's diff, placed on S hunk by hunk (`lines.py gold`): the lines of S that the fix removes or replaces (its `-` lines) and, for a hunk that only adds lines, the line before each run it adds. Every question's diff placed on S, and every `-` line matched S. A gold line is inside the pack when a whole file or an excerpt covers it with the file's own line numbers; a line shown only in an outline does not count. BM25 and truncation hold whole files. Tokens are counted with the Muse Spark Open tokenizer (Hugging Face revision 4239e4db). Budgets are 16K to 1M tokens (16,384 to 1,015,808; 128K is 131,072).

**Metrics.** File recall: the mean share of a question's gold files inside the pack, whole or as excerpts or outlines (the benchmark's context recall). (a) The share of questions with every gold line inside. (b) The mean share of gold lines inside. (c) The share of gold files with all their gold lines inside, pooled over the questions. Changes are paired by question, with 95% bootstrap intervals (2,000 resamples of questions, seed 1). Made with `lines.py compare` and, for the references, `lines.py report`. The line that starts each comparison and each reference table names the row files it was made from; the row files are not published.

**Builds.** 0.1.9 is the release build. The 0.1.10 candidate is a build of 0.1.10's pack and HTML changes, made before the fixes of its code review. Each build ran on indexes it built itself, on 27 Oct 2026. The final build, a build of 0.1.10's code after those fixes (before its version numbers were set), was measured again on the development questions only, on 28 Oct 2026 (the last table).

**What was tuned on.** The settings of 0.1.10's pack changes were chosen on the 200 development questions (kubernetes, home-assistant, angular, keycloak and godot, 40 each), so their numbers are tuning numbers, not test results. The 90 held-out questions (pytorch, vscode and elasticsearch, 30 each) are never tuned on: the candidate was measured on them once, beside a run of 0.1.9 on the same questions.
