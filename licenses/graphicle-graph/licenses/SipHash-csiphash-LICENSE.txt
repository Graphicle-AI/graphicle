SipHash (csiphash by Marek Majkowski, as used in CPython's Python/pyhash.c)

src/python_compat.rs computes SipHash-1-3 as CPython 3.12's Python/pyhash.c
does. That file contains Marek Majkowski's implementation of SipHash; its note
is reproduced below, verbatim as CPython 3.12 quotes it in Doc/license.rst
("SipHash24"). CPython's own licence is in PYTHON-LICENSE.txt.
